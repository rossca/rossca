# Sansala · Modelo 4 «Definitivo» (prototipo no oficial)

Versión final que reúne lo mejor de los modelos 1–3 siguiendo [`PROMPT-MODELO-4.md`](PROMPT-MODELO-4.md).

- **Ver:** abre `dist/index.html` (archivo único). `?static` desactiva las animaciones.
- **Desarrollo:** `npm install && npm run build` (usa las imágenes de `../prototype/img/w`).
- **Nota:** se compila con esbuild en JS en lugar de Vite + TypeScript, para entregar un único HTML autocontenido.
